# @onetwosmall/plugin-system-enhancement

NocoBase 系统增强插件，提供表格增强与登录页自定义功能。

## 简介

该插件为 NocoBase v2（V2-Client）提供开箱即用的系统增强能力，包括表格列宽拖拽调整与登录页深度自定义。所有配置均通过专用设置页面管理，保存后即时生效，无需修改代码。

## 功能特性

- **表格列宽调整**：拖动列头分隔线即可调整表格与子表格列宽；支持按页面（flow 设置）持久化列宽
- **登录页自定义**（作用于 `/signin`、`/signup`、`/forgot-password`、`/reset-password`）：
  - 背景图上传（支持 SVG、GIF、PNG、JPG、WebP），可配置尺寸、重复方式与位置
  - 表单位置（靠左 / 居中 / 靠右）及水平、垂直偏移（px）
  - 标题字体设置：字号、字重、字体颜色
  - 实时预览面板，保存前即可查看效果
- 设置页含两个页签：**表格增强** 与 **登录页自定义**
- 设置集合（`systemEnhancementSettings`）在首次启用时自动初始化默认值

## 安装

安装后，在 NocoBase 插件管理页面启用该插件：

```bash
yarn nocobase pm enable @onetwosmall/plugin-system-enhancement
```

## 配置说明

启用插件后，打开 **设置 > 系统增强** 进行配置：

| 页签 | 选项 | 说明 |
| --- | --- | --- |
| 表格增强 | 启用表格列宽拖动调整 | 控制表格与子表格区块的列宽调整功能（默认开启） |
| 登录页自定义 | 背景图片 | 上传登录页背景图片 |
| 登录页自定义 | 表单位置 | 登录表单位置：靠左 / 居中 / 靠右 |
| 登录页自定义 | 水平 / 垂直偏移 (px) | 登录表单的像素级偏移量 |
| 登录页自定义 | 标题字体设置 | 登录页标题的字号、字重与字体颜色 |
| 登录页自定义 | 背景设置 | 背景尺寸、重复方式与位置 |

## 注意事项

- 本插件面向 NocoBase v2 客户端运行时（`/v/admin`）
- `systemEnhancementSettings` 集合为公开只读，以便在登录前应用登录页样式；修改需登录后操作
- 自定义样式仅在认证页面注入，离开后自动移除
